# goadvertising-site

Modern static site for GO Advertising (goadvertising.io) — Lifeline free wireless service (Assurance Wireless partner page / BGOC) + Go Broadband. California-specific copy describes Assurance's free, basic smartphone for eligible California customers. GEO/SEO optimized (schema, llms.txt, sitemap). Hosted on GitHub Pages.

Contact form posts to Formspree — replace REPLACE_WITH_FORMSPREE_ID in index.html.
